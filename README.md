# 🏏 Cricket Scorecard Management System

Ek simple aur efficient project jo cricket match ke scores, runs, wickets, aur overs ko track karne ke liye banaya gaya hai. Yeh application ball-by-ball scoring ko manage karne aur detailed scorecard dikhane me madad karti hai.

---

## 🚀 Features (Khas Baatein)

* **Live Scoring:** Ball-by-ball update track karna (jaise runs, dots, aur boundaries).
* **Extras Management:** Wides, No-balls, Byes, aur Leg-byes ko easily record karna.
* **Player Statistics:** 
  * Batsmen ke runs, balls faced, aur strike rate ka track rakhna.
  * Bowlers ke overs, maiden overs, runs diye gaye, aur wickets ka record rakhna.
* **Automatic Calculations:** Current Run Rate (CRR) aur total overs auto-calculate hote hain.
* **Match Summary:** Innings khatam hone par pura scorecard aur match ka result display hota hai.

---

## 🛠️ Tech Stack (Technologies Used)

* **Language:** Cpp
* **Storage:** Local File / Console Output
